# Rayane Web Studio

Application multi-pages Vite + TypeScript avec authentification Google/Gmail (Firebase Auth), messagerie interactive (`messages.html`), annonces (`annonces.html`) et publications (`publications.html`).

## Démarrer dans VS Code

1. Ouvrez ce dossier dans **VS Code**.
2. Installez les dépendances :
   ```bash
   npm install
   ```
3. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```
4. Ouvrez [http://localhost:3000](http://localhost:3000) (ou `login.html` comme page d'entrée obligatoire avec connexion Google/Gmail).
5. Build de production :
   ```bash
   npm run build
   ```
